# Sample metadata

Sample_Metadata_All_Projects.csv combines the metadata columns of the seven bundled analysis-ready checkpoints without inferring missing fields. Record_Key, BioProject, Run_ID, BioSample_ID, Patient_ID and Specimen_ID provide accession and analysis linkage. Rows are checkpoint records and must not be summed as unique participants across analysis roles.

This is an identifier and clinical metadata crosswalk, not a claim of complete MIxS compliance. Source-study collection dates, geography, extraction details, clinical exposures and experimental controls may be absent from the checkpoint. Consult the original BioSample records and source studies for those fields. No unavailable values have been invented. Source Sample_Type and original time labels are retained rather than converted to unverified ontology identifiers.
